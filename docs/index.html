Adding it manually

  1. Google Calendar — Other calendars → + → From URL → paste the feed URL.
  2. Apple Calendar — File → New Calendar Subscription → paste the feed URL.
  3. Outlook — Add calendar → Subscribe from web → paste the feed URL.

Subscribe to the URL rather than downloading the file — a downloaded copy is a one-time snapshot and never updates.
